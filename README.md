📘 README — Абсолем ПроРост
Финальная версия сайта: карьерное консультирование и профориентация подростков и взрослых.

🎯 Что это
Статический сайт (HTML + CSS + JavaScript) с админ-панелью, чат-ботом, поиском, тёмной темой и cookie-баннером.
Без фреймворков, без сборки, без базы данных. Хостится на GitHub Pages.

Ключевая идея: заказчица сама управляет контентом через скрытую админку — программист не нужен для рутинных правок.

🚀 Как запустить
Локально
Скачай папку проекта.

Открой index.html в браузере — всё работает без сервера.

⚠️ Для корректной работы CMS нужен локальный сервер. Иначе открывай index.html с GitHub Pages.

На GitHub Pages
Залей все файлы в репозиторий glubkov2020-netizen/-_- (или свой).

Зайди в Settings → Pages → Source → Deploy from branch → main → / (root).

Через 1–2 минуты сайт будет доступен по адресу вида https://glubkov2020-netizen.github.io/-_-/.

🤖 Чат-бот
Что умеет
Отвечает на вопросы про направления, услуги, стоимость, длительность.

Показывает документы, отзывы, журнал.

Понимает контекст: если спросили про подростков — запоминает тему.

Помнит имя пользователя («Меня зовут Анна» → обращается по имени).

Работает в рамках сессии (при закрытии браузера история сбрасывается).

Как расширить
В js/chatbot.js есть массив scenarios — добавь новый сценарий:

javascript
{
    id: 'newtopic', weight: 7,
    match: (q) => /(ключевое_слово1|ключевое_слово2)/.test(q),
    reply: (d) => ({
        text: 'Ваш ответ',
        actions: [{ label: 'Кнопка', href: 'index.html#contact' }],
        suggest: ['Подсказка1', 'Подсказка2']
    })
}
Чем выше weight — тем приоритетнее сценарий.

🎨 Тёмная тема
Три режима: светлая, тёмная, авто (по системным настройкам).

Выбор сохраняется в localStorage.

Переключатель — в шапке сайта (справа).

Все цвета — в css/variables.css и css/themes.css.

📊 Статистика (опционально)
Используется GoatCounter — бесплатный, без cookie.

В админке → вкладка «Статистика» → введи поддомен (например, obraz).

После подключения цифры появятся в той же вкладке.

📝 Decap CMS (управление контентом через GitHub)
Что это
Веб-интерфейс для редактирования content/*.json напрямую в GitHub.
Полезно, если хочешь чтобы заказчица могла менять контент без правок в браузере (правки уходят в коммит).

Как подключить
Создай OAuth-приложение на GitHub: Settings → Developer settings → OAuth Apps.

Пропиши в config.yml:

yaml
backend:
  name: github
  repo: glubkov2020-netizen/-_-
  branch: main
  base_url: https://api.netlify.com  # или свой OAuth-сервер
Открой index.html (тот, что в корне, не главную!) → откроется админка Decap CMS.

Если OAuth настроить сложно — можно оставить только локальную админку (admin.js). Она проще и не требует сервера.

Что	Статус

PDF-документы	Используются HTML-версии. Можно подставить PDF в assets/docs/
Бот — сценарный	Не AI. Для AI нужен API-ключ (OpenAI / DeepSeek)
Статистика	Только после подключения GoatCounter

Логин/пароль — демо. Замени в js/admin.js:

Для настоящей продакшн-версии — используй Decap CMS с OAuth (GitHub OAuth).

📱 Мобильная оптимизация
